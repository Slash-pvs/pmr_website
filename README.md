#  pmr_website — Site du Pays Médoc Rugby (CMS)

**Description**
Site web CMS du Pays Médoc Rugby, permettant la gestion dynamique d’articles, d’une boutique, des contacts, des partenariats, et de diverses pages (école de rugby, pôle jeunes, etc.). Basé sur PHP avec frontend en CSS/JS.

## Fonctionnalités
- Gestion d’articles (CR(U)D)  
- Boutique en ligne simplifiée  
- Formulaire de contact & administration des contacts  
- Gestion des partenaires (ajout / modification)  
- Pages statiques personnalisées (école de rugby, pôle jeunes…)  
- Authentification / dashboard d’administration  
- Téléversement d’images, navigation dynamique, gestion du panier

## Technologies
- **Langage backend** : PHP  8.1
- **Frontend** : CSS, JavaScript  
- **Structure** : fichiers `*.php` pour les modules (ex. `article_crud.php`, `boutique.php`)  
- **Assets** : dossiers `css/`, `img/`, `js/`
